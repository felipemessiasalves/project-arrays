# 🍔 Project Arrays — DevClub Burger

Projeto prático para treinar os principais **métodos de array do JavaScript** (`forEach`, `map`, `reduce` e `filter`) usando como tema um cardápio de hamburgueria.

🔗 **Demo online:** https://felipemessiasalves.github.io/project-arrays/

---

## 📋 Sobre o projeto

A aplicação exibe os itens de um cardápio e oferece botões que aplicam, na prática, cada método de array sobre a lista de produtos:

| Botão          | Método      | O que faz                                      |
| -------------- | ----------- | ---------------------------------------------- |
| Mostrar tudo   | `forEach`   | Percorre a lista e exibe todos os itens        |
| Mapear         | `map`       | Cria uma nova lista transformando cada item    |
| Somar tudo     | `reduce`    | Reduz a lista a um único valor (soma total)    |
| Filtrar        | `filter`    | Retorna apenas os itens que atendem a um critério |

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)

## 🧠 Conceitos praticados

- Manipulação do DOM
- Métodos de array: `forEach`, `map`, `reduce`, `filter`
- Arrow functions
- Eventos de clique
- Renderização dinâmica de listas

## 📦 Como executar localmente

```bash
# Clone o repositório
git clone https://github.com/felipemessiasalves/project-arrays.git

# Entre na pasta
cd project-arrays

# Abra o index.html no navegador
```

Não é necessário instalar dependências: basta abrir o arquivo `index.html` no navegador.
